### Description

Byte-exact disassembly of Dragon Ball Z: The Legacy of Goku II (GBA, USA). Code is ARM/Thumb assembly; assets rebuild from your own ROM. No game data included. This is an assembly reconstruction and development resource, not a playable ROM hack or a recovery of the original C source. Rebuilding requires the owner's own supported retail ROM and the documented toolchain. The README describes remaining reconstruction and readability work; no completion percentage or independently tested runtime claim is asserted here.
