### Description

DragonByte Z and the Webfoot SDK: ROM editing tools and documented formats for the Legacy of Goku GBA games. The repository identifies this as an actively developed, pre-1.0 SDK and authoring initiative for The Legacy of Goku, The Legacy of Goku II and Buu's Fury. The current creator application and the planned next-generation application have distinct scope; development goals are not presented as shipped features. Supply your own supported ROM. No ROM or game data is distributed.
