# Development skill investigation

All four requested sources were inspected through their current public repositories and installed into this project's ignored `.agents/skills/`, using the existing Codex Skill Installer helper with an explicit `--dest` and immutable commit refs. [skills-lock.json](skills-lock.json) records the exact repositories, paths and revisions. They become discoverable by Codex on a subsequent turn; their reviewed text and applicable guidance were read directly during implementation. No global plugin or agent configuration was changed.

| Skill | Source and compatibility | Actual use |
|---|---|---|
| image-to-code | [Leonxlnx/imagegen-skills](https://github.com/Leonxlnx/imagegen-skills), `skills/image-to-code`; text skill explicitly aimed at Codex, no required executable dependency | Original-resolution image analysis, measured layout extraction, render/compare/correct. Its mandatory new-image generation defaults conflict with the approved-design instruction and were not followed. No new concepts or paid image requests. |
| frontend-design | [anthropics/skills](https://github.com/anthropics/skills), `skills/frontend-design`; standard SKILL.md, no required scripts/runtime | Subject-specific hierarchy, typography, restraint and screenshot critique. The approved mockup overrides brainstorming/redesign defaults. |
| ui-ux-pro-max | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), `.claude/skills/ui-ux-pro-max`; standard instructions and a Python 3 standard-library CSV search tool | Reviewed scripts/imports and searched focused keyboard-focus and Astro-static guidance. No design-system regeneration or persisted alternative. Already normalized catalog artwork remains authoritative instead of re-encoding through another asset pipeline. |
| web-design-guidelines | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills), `skills/web-design-guidelines`; text review skill compatible with Codex | Fresh [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) were read for labels, focus, heading order, safe content layout, reduced motion, accessible controls and image sizing. Applicable checks were applied to `website/` and browser tests. |

Installation behavior was checked before use. The Codex helper downloads source archives, validates paths/links and copies the requested skill directory; it does not execute a repository's installer. Its download mode was used at pinned commits. Third-party global npm/CLI/plugin installers were not run. Skill bodies were scanned for silent global installs/piped remote execution. The UI/UX search path uses sibling Python modules and local CSVs; its optional persistence/temp-file logic was inspected but not used. Focused searches returned relevant keyboard-focus and Astro results; unverified search suggestions were not treated as authority.

This is a targeted installation/code inspection, not a claim of a full supply-chain audit. The skills were not copied into production assets, the application dependency graph, catalog state or backups. No key, token or private account data was sent to their repositories. The frontend's operational commands require only Node and normal GitHub tooling.

To reproduce the optional local skill setup in Codex, use its installed `skill-installer/scripts/install-skill-from-github.py` with each locked `--repo`, `--path`, `--ref`, `--method download` and `--dest .agents/skills`. Review any changed upstream revision before updating the lock. The project's `.gitignore` deliberately keeps installed aid code and approved local reference artwork out of publication.
