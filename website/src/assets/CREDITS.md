# Decorative game artwork and provenance

`log2-canyon.png` is the Canyon background from **Dragon Ball Z: The Legacy of Goku II**, credited to contributor **Son Gohan** by [Sprite Database](https://spritedatabase.net/file/2915). The original game graphics belong to their original creators and rights holders; this asset is not original Hub artwork and is not covered by the Hub code license.

The owner explicitly authorized authentic trilogy game assets for this noncommercial fan site during LOG-HUB-004C. During the final refinement the owner explicitly instructed that the Canyon asset remain in the build after the redistribution issue was raised. This is ambient interface scenery, never a submitted project's cover or screenshot. No ROM file is included. The source PNG is unchanged. CSS uses native 256px scaling on mobile and 512px integer scaling on desktop, preserving square pixels and aspect ratio.

`buus-fury-portrait-frame.png` and `buus-fury-portrait-ornaments.png` contain only golden border pixels from a portrait frame from **Dragon Ball Z: Buu's Fury**, sourced from [Omega's portrait sheet on Sprite Database](https://spritedatabase.net/file/21488). The owner specifically requested these frames. The source crop is x=33, y=54, width=64, height=64. The pink sheet background, non-frame colors and the interior 48 x 48 portrait region are transparent. The first file repeats plain edge samples; the second supplies one complete center ornament per side, including its inner highlight detail. All visible pixels retain their source colors; no character pixels are included. Featured detail frames use 2x corners at every width; homepage featured frames use 2x on desktop and native size on mobile. Ordinary detail artwork uses native-size corners. Only plain border texture repeats. Four non-repeating overlay pieces keep one complete ornament centered on each side. CSS clips the panel background to its padding box so transparent corners show the scenery rather than an opaque backplate. The complete sheet is not shipped.

## Permission status

No redistribution license from the original game rights holders has been established for either asset. The source pages credit their contributors and describe private/noncommercial availability; that is not treated here as proof of a rights-holder grant. Attribution and the owner's instruction are recorded accurately, not represented as legal permission. The assets remain in the candidate under the owner's explicit instructions. This unresolved redistribution issue remains part of the handoff and independent review.

`sources.json` records exact source page/image URLs, dimensions, byte sizes, SHA-256 values and the portrait crop. Both assets are self-hosted through Astro/Vite without external runtime requests. Neither is included in the Hub code license. No raw sprite archive, unrelated artwork, or obsolete DragonByte screenshot is included.

## Owner-selected game scenery

The owner supplied the exact Spriters Resource sheets locally: [LoG I Kame House, Fab & Nrt](https://www.spriters-resource.com/game_boy_advance/dbzlog/asset/594384/), [LoG II East District 439 Autumn, SpYn_](https://www.spriters-resource.com/game_boy_advance/dbzlog2/asset/484628/), and [Buu's Fury Check-In Station, -Bwar-](https://www.spriters-resource.com/game_boy_advance/dbzbuusfury/asset/53228/). Crops isolate Kame House, Goku's House exterior and Snake Way's head respectively, excluding sheet labels and unrelated areas. Source attribution is preserved here. Source hashes, dimensions and exact crop rectangles are in sources.json. Crops retain native pixels without rescaling and strip incidental sheet metadata. No full map sheet or ROM is shipped.

These three game-specific images supersede the earlier Canyon selection. One nonrepeating scenery element follows the displayed project's base game, or the homepage's featured project. Multiple-game and empty views have no game-specific scenery. Original Canyon and its provenance remain in source; it is no longer the selected background. The existing unverified rights-holder redistribution status applies to all game artwork, including these owner-selected sheets.
